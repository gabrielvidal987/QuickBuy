Para iniciar o MySQL Server no Windows, execute o comando net start mysql no Prompt de Comando aberto como Administrador. [1] (https://translate.google.com/translate?u=https://superuser.com/questions/666521/how-do-i-start-a-mysql-server-on-windows&hl=pt&sl=en&tl=pt&client=sge)No WindowsPelo Prompt de ComandoPressione a tecla Windows e digite cmd.Clique com o botão direito em Prompt de Comando e escolha Executar como Administrador.Digite o comando abaixo e aperte Enter:bashnet start mysql
Use o código com cuidado.
